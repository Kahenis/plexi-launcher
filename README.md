# plexi-launcher

Dépôt d'installation de Plexilauncher, l'écran d'accueil Android TV / Google TV pensé pour Plexi Play.

- **Télécharger l'APK** : [Plexilauncher.apk](https://raw.githubusercontent.com/Kahenis/plexi-launcher/main/Plexilauncher.apk) (version indiquée dans `version.json`).
- Plexilauncher vérifie lui-même ce dépôt au démarrage puis une fois par jour, et propose l'installation des nouvelles versions.
- Nécessite Plexi Play 1.9.3.2 ou plus récent pour afficher les films et séries Plex.

Ce dépôt ne contient que l'application compilée.
